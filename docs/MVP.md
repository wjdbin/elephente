# 엘펜그라운드 MVP 명세서

3주 범위는 **Must + Should**만. Could(결과·소개·부원)와 알림은 빼 둔다.

## 1. 서비스 정의

| 항목 | 내용 |
|------|------|
| 이름 | 엘펜그라운드 |
| 한 문장 | 엘펜 부원이 톡방에 흩어진 훈련·경기·대회·결과를, 달력·소개·부원·기록 한곳에서 보게 하는 서비스. |
| 이번 3주 초점 | **오늘/다음 훈련·경기 시간·장소**를 바로 보고, **다가오는 대회 일정**도 같은 링크에서 확인한다. |

## 2. 페르소나

| 요소 | 내용 |
|------|------|
| 누구 | 김민재, 21세, 2학년, 엘펜 축구 부원 |
| 하루 | 수업·알바·과제로 바쁘고, 동아리 톡은 쌓아 둔 채 잘 안 읽는다. |
| 목표 | 훈련·경기에 빠지지 않고, 맞는 장소로 가며, 대회가 언제인지도 대략 안다. |
| 불편 | 일정·장소·대회가 톡에 섞여 찾기 싫고, 헛걸음·지각이 난다. |
| 지금 방법 | 톡 고정·최근 공지 훑기, 동기에게 “오늘 어디야?” / “대회 언제야?” 묻기. |
| 한줄요약 | 축구는 오지만 톡·공지 관리는 귀찮아하는 타입. |

## 3. 가상 인터뷰 요약

| 구분 | 내용 |
|------|------|
| 안 쓰게 된 이유 | ① 톡보다 정보가 늦음 ② ‘오늘 뭐지’가 바로 안 보임 ③ 링크 습관이 없음 |
| 톡이 더 편한 이유 | 카톡은 이미 켜져 있고, 물으면 지금 답이 온다. |
| 대응 | 톡 **전** 갱신(담당 1명) + 오늘 시간·장소 + 갱신 시각 + **다가오는 대회만 짧게**. 가입·알림 강요 없음. |

## 4. 기능 정의 (MoSCoW)

| 기능명 | 한줄설명 | 우선순위 | 이유 |
|--------|----------|----------|------|
| 오늘 훈련 고정 카드 | 열자마자 오늘/다음 시간·장소가 맨 위 | Must | 안 버리면 끝나는 핵심. 외부 서버 없이 가능 |
| 한 달 달력 | 이번 달 훈련·경기·대회를 날짜로 봄 | Should | 한 문장의 ‘달력’ |
| 지난번 갱신 시각 | 정보가 언제 고쳐졌는지 표시 | Should | 틀리면 다시 안 염 |
| 장소·시간 상세 | 눌러서 몇 시·어디서만 짧게 | Should | 확인 한 방 |
| 대회 일정 목록 | 다가오는 대회 날짜·이름·장소 | Should | 훈련만으로는 ‘대회’ 흩어짐이 안 풀림 |
| 결과·소개·부원 목록 | 짧은 글·리스트 | Could | 시간 남으면 |
| 카톡용 고정 링크 | 가입 없이 URL만 | Could | 배포 수단 |

## 5. 사용자 흐름 (화면 3개)

| 화면 | 뭘 보나 | 어디로 가나 |
|------|---------|-------------|
| 1. 첫 화면 | 오늘/다음 카드 + 갱신 시각 + 곧 있는 대회 1~2줄 | 달력 → 2. 대회 더보기 → 3. 카드/자세히 → 상세 |
| 2. 한 달 달력 | 훈련·경기가 날짜 칸에, 대회는 표시만 다르게 | 날짜/일정 → 상세. 홈 → 1. 대회 목록 → 3 |
| 3. 대회 목록 | 다가오는 대회만 날짜·이름·장소 리스트 | 한 줄 클릭 → 그 대회 상세. 홈 → 1 |

상세는 별도 페이지(`/events/:id`)로, 시간·장소만 짧게 보여 준다.

## 6. 이번에 안 할 것 (Won't)

| 기능 | 안 하는 이유 |
|------|----------------|
| 다음 일정 복사 | 톡에 다시 흩어져 ‘한곳’ 습관이 약해짐 |
| 지도 앱으로 열기 | 학교 장소는 이름이면 충분 |
| 3시간 전 알림 | 귀찮고, 권한·탭에 의존해 믿기 어려움 |
| 이번 주만 모아보기 | 카드+달력과 겹침 |
| 로그인·문자/카톡 자동발송 | 3주·혼자·무료 범위 밖 |
| 경기 결과·소개·부원 (필수로) | 이번엔 Could — 대회 일정 넣은 뒤 시간 남으면 |

## 운영 (기능 아님, 필수)

| 규칙 | 내용 |
|------|------|
| 담당 | 일정·대회 고치는 사람 **1명** |
| 순서 | **톡에 올리기 전에** 엘펜그라운드부터 고친다 (훈련·대회 모두) |
| 확인 | 주 1회, 갱신 시각이 최근에 바뀌었는지 본다 |

## 3주 일정

1. 1주: 오늘 카드 + 갱신 시각
2. 2주: 달력 · 상세 · 대회 목록
3. 3주: 배포 · 모바일 · 운영 습관

이 명세서로 3주 안에 완주 가능하다. Must+Should(달력·상세·갱신·대회 목록)와 운영만 지키면 되고, 결과·소개·부원·알림은 빼도 된다.
