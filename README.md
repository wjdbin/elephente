# 엘펜그라운드

엘펜 축구 동아리 부원이 톡방에 흩어진 일정을, 한 링크에서 보게 하는 서비스입니다.

**정모 · 추가정모 · WUFL · SUFA** 시간과 장소를 바로 보고, 다가오는 대회도 같은 화면에서 확인합니다. 마스코트는 **엘펜이**입니다.

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:5173](http://localhost:5173) 을 엽니다.

환경 변수는 `.env.local` 에 둡니다.

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

## 화면

| 경로 | 화면 |
|------|------|
| `/` | 오늘/다음 카드 + 엘펜이(말풍선) + 갱신 시각 + 다가오는 WUFL·SUFA |
| `/calendar` | 한 달 달력. 뒤에 로고 워터마크, 오늘은 날짜에 주황 원. 칸에는 종류·시간·상대 |
| `/tournaments` | 다가오는 WUFL·SUFA 목록 |
| `/events/:id` | 그 일정의 시간·장소·상대·도착 시각 |
| `/edit` | 임원진만. 들어올 때마다 운영 비밀번호 |

달력에서 날짜를 누르면 상세가 열립니다. 종류는 색 타원 뱃지로만 보여 주고, 정모는 큰 제목을 쓰지 않습니다. WUFL·SUFA는 `vs 상대`와 경기 시작 **1시간 30분 전** 도착 시각을 넣습니다. 장소는 달력 칸이 아니라 상세에서 봅니다. 달력을 스크롤해도 위 헤더와 겹치지 않습니다.

## 일정 고치는 법 (담당 1명)

톡에 올리기 **전에** 사이트에서 먼저 고칩니다. 다시 배포하지 않아도 부원 화면에 바로 반영됩니다.

1. 오른쪽 위 **운영** 또는 `/edit` 으로 들어갑니다.
2. 운영 비밀번호를 입력합니다. 창을 나가면 다시 잠깁니다.
3. 종류(정모 / 추가정모 / WUFL / SUFA), 날짜, 시간, 장소를 넣습니다. 제목은 없습니다. 경기면 **상대 학교**도 넣습니다.
4. 저장한 뒤 홈·달력에서 확인하고 톡에 올립니다.

주 1회, 화면의 갱신 시각이 최근에 바뀌었는지 확인합니다.

## Vercel 배포

Vercel에서 이 저장소를 import 한 뒤, 아래만 맞추면 됩니다.

1. **Build Command**: `npm run build`
2. **Output Directory**: `dist`
3. **Environment Variables**
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
   값은 로컬 `.env.local` 과 동일하게 넣습니다.

`vercel.json` 에 SPA rewrite가 들어 있어서 `/calendar`, `/edit` 새로고침도 됩니다.

링크를 톡에 공유하면 `public/og.png` 미리보기가 나갑니다. 카카오톡에서 이미지가 안 보이면 `index.html` 의 `og:image` 를 `https://실제도메인/og.png` 전체 주소로 바꿉니다. OG를 다시 만들 때는 `npm run og` 입니다.

## 앱으로 설치

스토어 없이 홈 화면에 둘 수 있습니다. HTTPS(Vercel)에서만 설치 버튼이 뜹니다.

- **Android / Chrome**: 화면 위 **설치하기**, 또는 브라우저 메뉴의 앱 설치
- **iPhone**: Safari에서 공유 → **홈 화면에 추가**
